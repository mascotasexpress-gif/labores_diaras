# 🐾 Mascotas Express — Sistema Clínico Integral v2025

Sistema profesional de gestión clínica para veterinarias. Integra protocolos médicos, KPIs, gestión de pacientes, evaluaciones de desempeño y análisis de tendencias.

## ✨ Características

### Dashboard Ejecutivo
- Métricas en tiempo real (hospitalizados, consultas, satisfacción)
- Alerta de urgencias activo
- Tabla de pacientes hospitalizados con estado
- KPIs críticos con indicadores de cumplimiento

### 13 Módulos Operativos
1. **Pacientes** — Gestión de historiales clínicos
2. **Protocolos** — 7 áreas clínicas con procedimientos paso a paso
3. **KPIs** — 46 indicadores por rol (Médico, Auxiliar, Peluquero)
4. **Checklist** — 68 ítems de verificación diaria
5. **Turnos** — Acta de entrega entre colaboradores
6. **Evaluaciones** — Fichas mensuales de desempeño
7. **Tendencias** — Análisis histórico de KPIs
8. **Incidentes** — Registro y seguimiento de eventos
9. **Urgencias** — Protocolos de emergencia y carro de urgencias
10. **Consentimientos** — Formularios de consentimiento informado
11. **Admin** — Configuración, usuarios y permisos
12. **Reportes** — Exportación de datos y documentos
